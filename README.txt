GOPHER TORTOISE TRACKER - upload to GitHub from your iPhone

Files: index.html (the whole app) and sw.js (lets it work offline). Upload both.

1. In Safari, go to github.com, sign in, tap + > New repository. Name: tortoise-tracker. Public. Create.
2. Tap "uploading an existing file". Choose both files from the Files app (unzip this first). Tap Commit changes.
3. Settings > Pages > Source "Deploy from a branch", Branch main, folder / (root), Save.
4. In 1-2 minutes open https://YOUR-NAME.github.io/tortoise-tracker/ in Safari.
5. Share button > Add to Home Screen. Open it from the icon from then on.

Notes: Safari and the icon keep separate records. Deleting the icon deletes records. Use Stats > Save a backup file now and then.
